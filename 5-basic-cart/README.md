# 5 - Basic cart

![php-to-rust logo](../images/php-to-rust.png)

Four functions on a `Vec<String>`: add, total length, longest borrow, and remove. Matches the Ownership exercise in PHP to Rust.

## Run

From this folder:

```bash
cargo test
cargo run -q
```

Expected `cargo run` output:

```text
ciabatta
21
Some("espresso")
["ciabatta", "pesto"]
```
